# handoff · 长期交接

给 [Aurabot](https://github.com/aureth-labs/dsh-aurabot-qq) 用的扩展模块：**会话满了，她自己翻篇，但不失忆。**

---

## 问题

Aurabot 里一个 QQ 私聊/群**永久绑定一个 DSH 会话**。上下文到顶之后只有两条路：被压缩（越压越糊）或者宕机。而一旦归档，逐字原文就再也读不到了——她会"记得"你这个人，但背不出你说过的话。

## 这个模块做什么

到阈值时自动做五件事：

1. **让她用第一人称写 3–5 条笔记**（不是档案，是写给自己看的备忘录，带情绪和判断）
2. **逐条写进记忆库**（拆成独立条目，以后每一条都能被单独检索到）
3. **记下旧会话的 id**，归档旧会话
4. **新会话开场注入笔记 + 最近 40 条原话** → 不断档
5. **给她一个 `recall_history` 工具** → 想不起细节时，自己按关键词翻旧章节原文

## 安装

把 `index.mjs` 放到：

```
Windows: C:\Users\<你>\.dsh\plugins-data\aurabot\modules\handoff\index.mjs
macOS/Linux: ~/.dsh/plugins-data/aurabot/modules/handoff/index.mjs
```

目录不存在就新建。Aurabot 会自动发现并热加载，日志里会出现：

```
[modules] 模块「长期交接」（自己写的）已启动
```

**修改后保存即生效**（约 8–10 秒自动重载），不用重启 DSH。

## 命令（主人在 QQ 里发）

| 命令 | 作用 |
|---|---|
| `/交接` | 立刻交接一次（会自动判断在哪个聊天里发） |
| `/交接状态` | 看计数：`12k / 100k token（38 条，缓冲 40 条），上次交接 3 天前` |
| `/交接自检` | 健康度：开关、阈值、便条条数、历史可翻、计数是否在涨 |

## 她自己会用的工具

| 工具 | 说明 |
|---|---|
| `recall_history` | 按关键词翻旧章节原文（只读，不会打扰对方）。返回带时间和说话人的片段，她转述给你听 |

触发方式很自然，比如你问「你还记得我们最早聊的是什么吗」，她会自己去翻。

## 参数

在 Aurabot 面板 → 扩展 → 长期交接 里改。

| 参数 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 启用 |
| `maxTokens` | `100000` | 累计多少 token 后交接（按日聊 200 条约 23 天） |
| `maxDays` | `30` | 兜底：多少天没交接也交一次 |
| `recentLines` | `40` | 交接时带走多少条最近原话 |
| `notify` | `true` | 交接后跟主人说一句：`稍等我一下，脑子要装满了，我去倒点水出来。` |
| `hint` | 见代码 | 便条的写作要求（第一人称、带情绪、写清最后几轮） |

**改代码里的 `defaults` 不会影响已经装好的机器**——已保存的设置优先。升级方式见下。

## 升级

覆盖 `index.mjs` 即可，**设置不会丢**（设置在 `config.json`，代码在 `index.mjs`，互不影响）。

1. 覆盖文件
2. 等 8–10 秒（日志出现 `模块「handoff」文件改了，重新加载`）
3. 让她发 `/交接自检` 确认版本和参数

## 记忆能留多久

| 资源 | 上限 | 换算 |
|---|---|---|
| 历史章节指针 | 500 条 | 按 23 天一次 ≈ **31 年** |
| 单次检索范围 | 80 个旧章节 | 翻 80 个约 5 秒封顶 |
| 会话文件 | 不自动删除 | 归档只是从侧栏隐藏，文件仍在 `~/.dsh/sessions/` |

**会真正丢失的情况只有两种**：手动删掉了会话目录；或者问法跟旧内容对不上关键词（问"那个东西"而记录里是"农场"）。

## 依赖

- Aurabot（DSH 扩展框架）
- **Node.js ≥ 22.15**（用到内置 `zlib.zstdDecompressSync` 解会话文件）
